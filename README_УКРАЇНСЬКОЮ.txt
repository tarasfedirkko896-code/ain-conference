AIN CONFERENCE — ПРОТОТИПНА КАРТА WORKADVENTURE

Це справжня tile-based карта Tiled/WorkAdventure: map.tmj + map.wam + графічні tilesets.
Вигляд максимально повторює наданий користувачем концепт, бо використовує його як основу графічного tileset.
Сцена, зона слухачів, backstage, медіазона, дискусійна та нетворкінг-зона задані у map.wam.
Зверніть увагу: на графіці присутні намальовані персонажі та предмети; вони є частиною фону, не окремими інтерактивними об’єктами.
Партнерські бренди — лише демонстраційні макети, не підтверджені спонсори.
Розміщення колізій приблизне, потребує тестування проходів.
Трансляція, одночасні 200 учасників, права спікерів і робота аудіо потребують перевірки на реальному сервері та відповідного тарифу.

ЯК ЗАПУСТИТИ:
1. Розпакуйте ZIP і збережіть структуру папок.
2. Відкрийте map.tmj у Tiled для редагування.
3. Опублікуйте всі файли на HTTPS-хостингу з правильними MIME types, наприклад GitHub Pages.
4. У WorkAdventure створіть окрему кімнату і вкажіть повний HTTPS URL до map.tmj як Map URL.
5. Перевірте проходи та зони Podium/Audience, перш ніж використовувати на події.
